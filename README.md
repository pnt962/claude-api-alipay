## 先说结论：官方渠道不存在“支付宝充 API”这回事

Anthropic 的收银台只认 Visa、Mastercard、American Express 这类信用卡，外加 PayPal（还得绑外币卡）。银联、支付宝、微信，在官方付款那一步都过不去。

API 的计费逻辑也和很多人想的不一样，它不是月费制，而是预充值额度制：

- 使用前先在 Console 的计费页面（Settings → Billing）购买额度，调用按当前定价从额度里扣
- 只对成功的请求和已完成的任务收费，失败的请求不扣钱；但有个例外——如果请求本来能成功、你的客户端中途断开或超时，这笔照样计费
- 额度买完立即到账，余额和使用量在同一页面可见
- 可以设置自动充值：余额低于你定的阈值，就自动按设定金额补一笔

> 两个容易踩的坑写在官方文档里，但不少人充值完才看到：额度从购买之日起一年过期，过期日不能延长；所有额度购买不可退款。

官方还有一种“月度发票”模式，但那只面向通过销售团队签了发票安排的组织，月末由 Stripe 出账。个人开发者摸不到这条路，它和“支付宝充值”更是没有半点关系。

所以问题就变成了：手里只有支付宝和微信的人，怎么让人民币最终变成 Claude 的可用额度。

## 常见问题

**支付宝付的钱，最后用到的是官方服务吗？**

是。代订阅完成后，你的 Claude 账号直接升级为 Pro/Max，用的是 Anthropic 官方服务本身，区别只在收款的中间层。App 内订阅（礼品卡、Google Pay）同理，Anthropic 那边看到的是苹果或谷歌的账单。

**Pro 订阅自带的额度，够写代码用吗？**

Pro 包含 coding agent 的使用额度，日常开发基本够用，但不是无限量，重度使用会触顶，Max 档额度更高。另外按官方文档有个细节值得留意：订阅计划附带的月度 API 额度不能用于 coding agent 和 Claude 应用，而单独购买的预付额度涵盖 API、playground 和 coding agent。如果你对 API 形态的用量有要求，选档位前先把这条弄清楚。

**人民币付款会被封号吗？**

任何非官方原生付款方式都有风控概率，这个没人能打包票。能降低风险的做法：别把账号密码交给别人代登录（那种方式风险最高，坚决别用）；自己操作授权的平台注意账号安全；新号先养几天再订阅。走激活码类代充不交密码、苹果礼品卡走苹果账单，这两类相对更稳。

**额度或订阅到期了怎么办？**

订阅按周期走，单次订阅不想要下个月就不续。官方 API 额度用完就得手动再买，或者提前开好自动充值。过期的额度不会无声无息消失，会显示在计费页面的发票历史里。

**为什么 Anthropic 不直接收支付宝？**

它是美国公司，全球统一美元结算，没有开通国内本地支付通道。这不是针对个人用户，大部分海外 AI 服务都一个样。
